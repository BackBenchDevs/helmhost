# Appcast stubs

These XML files are **stubs** checked into git for local docs builds.

Live Sparkle / WinSparkle feeds (with enclosure signatures) are published by
`.github/workflows/release.yml` directly to GitHub Pages:

- https://docs.helmhost.bbdevs.com/appcast.xml
- https://docs.helmhost.bbdevs.com/appcast-rcs.xml

Do not commit signed production feeds here.
